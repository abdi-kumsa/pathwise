📋 1. Pre-Flight Checklist (Brand-New Laptop Setup)

Before installing anything, verify your Windows system settings:

A. OS Version Check

Press Windows Key + R, type winver, and press Enter. Ensures Windows 10 (64-bit Home/Pro) or Windows 11 is installed.

B. Hardware Virtualization Check

Press Ctrl + Shift + Esc to open Task Manager. Click Performance > CPU. Verify bottom-right shows Virtualization: Enabled.

🐳 Step 1: Install Docker Desktop & Enable WSL 2

PathWise is containerized. You do NOT need to install Python, Node.js, PostgreSQL, or Machine Learning libraries. Docker handles everything automatically.

🪟 Windows Installation Walkthrough
  1. Download installer: https://www.docker.com/products/docker-desktop/
  2. Double-click Docker Desktop Installer.exe. Ensure "Use WSL 2 instead of Hyper-V" is CHECKED.
  3. Click Close and restart when Windows prompts to finish setup.
  4. Launch Docker Desktop from the Start Menu, accept terms, click "Continue without signing in", and wait until status turns green ("Engine running").
💡 WSL 2 Prompt Fix: If Docker states "WSL 2 installation is incomplete", open PowerShell as Administrator and run: wsl --update, then restart Docker Desktop.

📦 Step 2: Extract Zip & Prepare Environment Configuration

  1. Locate your downloaded PathWise.zip file in Downloads.
  2. Right-click PathWise.zip and click Extract All... to your Desktop.
  3. Check that a file named .env exists inside the folder. If missing, copy .env.example and rename it to .env.

⚡ Step 3: Opening PowerShell in the Folder

Open File Explorer inside the unzipped PathWise folder. Click directly on the Address Bar at the top, type powershell, and press Enter. Terminal will open directly in the folder!

Then run:

docker compose up

🛑 Step 6: Stopping, Restarting & Diagnostics

To Stop: Press Ctrl + C in PowerShell, or run docker compose down.

To Restart: Ensure Docker Desktop is running, then run docker compose up.

Useful Diagnostic Commands

docker compose ps — Check running status of containers.

docker compose logs backend — Inspect backend server logs.

❓ Comprehensive Windows Troubleshooting

Q: PowerShell shows "docker: command not found"

Solution: Docker Desktop is not open. Search for Docker Desktop in your Windows Start Menu and wait until the status in the bottom-left corner shows green ("Engine running").

Q: Error "port 3000 or 8000 is already in use"

Solution: Another program on Windows is using port 3000 or 8000. Close active web servers or restart Windows to free up system ports.

Q: How do I reset to pristine demo sample data on Windows?

Run docker compose down -v followed by docker compose up in PowerShell to reset cached database volumes.
