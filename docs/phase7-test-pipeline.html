ml/monitor_models.py
  • Loads XGBoost from placement_xgboost.pkl
  • Evaluates on last 50 student records from features.parquet
  • Computes accuracy, F1, ROC-AUC
  • Flags drift if performance drops > 10 pp from baseline
  • Exit code 0 = ok, 1 = drift detected
  • Cron comment: every Monday at 07:00
ml/retrain_all.py
  • 5-step subprocess pipeline in dependency order
  • Step 1: feature_engineering.py (rebuild parquet)
  • Steps 2–4: train each model in FK-safe order
  • Step 5: generate_model_metrics.py (refresh JSON)
  • Stops immediately on any step failure and names it
