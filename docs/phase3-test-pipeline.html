The Data Foundation

Everything starts from data/build_parquet_from_csv.py. It reads two CSVs, merges them, scales features, and writes data/processed/features.parquet — the single input all ML scripts share. No database needed.

data/mock/students.csv + placements.csv
        ↓
data/build_parquet_from_csv.py
        ↓
data/processed/features.parquet   (3,000 rows × 24 cols)
        ↓
┌──────────────┬─────────────────┬──────────────┐
│ XGBoost      │ LSTM            │ Prophet      │
│ (placement)  │ (enrollment)    │ (job demand) │
└──────────────┴─────────────────┴──────────────┘

Model 1 — Feature Pipeline (ml/load_features.py + data/build_parquet_from_csv.py)

Transforms applied to raw CSVs:

  • MinMaxScaler → gpa_scaled, communication_score_scaled (both clamped to [0,1])
  • pd.get_dummies(prefix='prog_') → 12 one-hot programme columns
  • placed column: bool → int (critical fix — pandas reads "True"/"False" as booleans, not strings)

Model 2 — XGBoost (ml/train_xgboost.py)

Key design decisions:

  • Monotone constraints — gpa_scaled, internships, projects, communication_score_scaled all set to +1 (must increase). Programme dummies set to 0. This enforces that better students always get higher predicted probability.
  • n_estimators=100, max_depth=5, learning_rate=0.1, binary:logistic
  • Final metrics: Accuracy 87.83%, Precision 89.19%, Recall 98.11%, F1 93.44%

Model 3 — LSTM (ml/train_lstm.py)

Architecture:

Input(3, 1)  ← 3-year sliding window, 1 feature (enrollment count)
    ↓
LSTM(32, return_sequences=True)
    ↓
LSTM(16)
    ↓
Dense(1)     ← next year's enrollment count (normalized)
  • Per-programme MinMaxScaler fitted on 2019–2023 only; 2024 held out for test
  • EarlyStopping(patience=20), batch_size=8, up to 200 epochs
  • Rolling-forward inference: each predicted year feeds back as input for the next
  • RMSE on 2024 holdout: 7.88 students

Model 4 — Prophet (ml/train_prophet.py)

Design:

  • Monthly job-demand series derived from enrollment × 3 posting multiplier
  • Seasonal weights: Jan–Mar and Aug–Sep peaks (1.2–1.4×), Jun–Jul trough (0.6–0.7×)
  • Prophet(seasonality_mode='multiplicative', changepoint_prior_scale=0.15)
  • 6-month holdout for evaluation
  • MAPE 3.41%, RMSE 4.68 on holdout

Model 5 — SHAP (ml/explain_predictions.py)

Two APIs:

  • compute_shap_values(n_samples=200) — global feature importance across 200 test samples
  • explain_student(student_dict) — per-student breakdown of what drives their placement probability

Top features by mean |SHAP|: gpa_scaled (0.68), internships (0.46), communication_score_scaled (0.42), projects (0.28), then programme dummies.
