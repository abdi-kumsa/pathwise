# Feature importance (DOC1 steps 5–6)

Generated by `scripts/model_report.py` from `ml/models/ethiopia_feature_importance.json`. Do not edit by hand.

Importance is computed **after training**, on the pooled ridge model the forecasts use (horizon 1), trained on earlier target years and explained on later ones. It is reported **separately** from the DOC1 collection priorities (PROC.S6), which are data-collection weights, not model weights, and are never blended with these figures.

Three methods:

- **model-based** — |coefficient × feature standard deviation|
- **SHAP** — mean |coefficient × (x − mean x)|, which is exact SHAP for a linear model
- **permutation** — increase in holdout RMSE when one feature is shuffled

## Reading it

A negative coefficient on `distance_from_series_mean` is mean reversion: a value above its own history tends to fall back. On the simulated data this is the dominant effect, as expected from a persistent series. Every other DOC1 column is collected but is not a learner input; the API lists them under `unused_by_learner`.

Placement SHAP belongs to the leftover US model and appears only when it is switched on.
